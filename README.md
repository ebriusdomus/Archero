# MYTHOS — Mobile Action Roguelite

Working title for an original mobile action roguelite inspired by the immediacy of one-thumb room-based games, with its own mythological identity, heroes, enemies, progression and visual direction.

## First release: Greece

The first campaign is entirely based on Greek mythology.

- 25 levels
- 5 themed areas
- Multiple playable Greek heroes
- Unlockable heroes and equipment
- Minibosses and bosses
- Final Level 25 boss: Minotaur
- Portrait mobile gameplay
- One-thumb movement
- Automatic attack while stationary
- Three-choice upgrades during runs
- Permanent progression between runs

## Visual direction

Premium stylized 3D cartoon fantasy:

- Mythological characters with strong silhouettes
- Detailed but readable environments
- Large cinematic bosses
- Strong elemental VFX
- Clean mobile HUD
- Blue/gold heroic visual language for the initial Greek campaign

## Initial heroes

- Perseus — balanced hero / precision / mobility
- Heracles — strength / area damage / survivability
- Atalanta — attack speed / ranged specialization
- Achilles — aggressive spear fighter / high risk-high reward
- Theseus — close combat / labyrinth specialist
- Odysseus — traps / tactical control
- Orpheus — magical sound attacks / crowd control
- Medea — poison / curses / elemental magic

## Greece campaign structure

1. Levels 1–5: Ruins of Attica
2. Levels 6–10: Sacred Wilds
3. Levels 11–15: Temple of the Gorgons
4. Levels 16–20: Lost Labyrinth
5. Levels 21–25: Heart of the Labyrinth

### Key bosses

- Level 5 — Cyclops Guardian
- Level 10 — Calydonian Boar
- Level 15 — Medusa
- Level 20 — Labyrinth Guardian
- Level 25 — Minotaur

## Future mythology expansions

After Greece, the game can expand to other mythological traditions, for example Egypt, Rome/Italy, Japan, India, Norse mythology, Celtic mythology, Mesopotamia and Mesoamerica.

## Development target

Engine: Unity 6.3 LTS
Primary platform: Android
Later: iOS

The first milestone is a vertical slice with Perseus, one Greek environment, core movement/combat, upgrade selection, enemies and one miniboss.
